# HarmoniyaBridge

A Fabric mod that provides bridging functionality between Minecraft clients and external services.

## Features

- Network packet handling for client-server communication
- Configuration management for flexible setup
- Compatible with Fabric Loader and Minecraft

## Installation

1. Download the latest release from the releases page
2. Place the `.jar` file in your `mods` folder
3. Ensure you have Fabric Loader installed
4. Configure the mod as needed

## Requirements

- Minecraft (version specified in `gradle.properties`)
- Fabric Loader (version specified in `gradle.properties`)
- Fabric API (version specified in `gradle.properties`)
- Java 21 or higher

## Configuration

The mod can be configured through its configuration files. See the config package for available options.

## Building

To build the mod from source:

```bash
./gradlew build
```
